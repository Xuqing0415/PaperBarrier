把剪纸贴在窗上、光从背后透过来 —— 这才是它本来的样子。

白天我们看到的是「纸」：实心的红，柔和的投影，纸纤维的噪点。夜里我们看到的是「光」：
镂空的部分亮起来，红纸退成暗色的剪影。

实现上其实只有三件事：

### 一、一组变量

```css
:root {
  --paper: #f5f0e6;   /* 宣纸米白 */
  --red:   #c8102e;   /* 中国红 */
  --glow-alpha: 0;    /* 背后有没有灯 */
}

[data-theme="night"] {
  --paper: #0e0c0b;
  --red:   #7a0a1c;   /* 暗红剪影 */
  --glow-alpha: 1;
}
```

### 二、光要在纸的背后

关键在于 DOM 顺序：**光必须画在剪纸下面**。

因为我们的剪纸是「一条路径 + `fill-rule: evenodd`」，镂空处本来就是透明的 ——
只要背后放一层暖色渐变，光就自然从孔里透出来了。不需要任何混合模式，也不需要额外的图层。

```html
<div class="work__light"></div>   <!-- 背后的灯 -->
<svg class="papercut">…</svg>     <!-- 纸，挖空了 -->
```

### 三、切换时不要跳变

CSS 变量本身不能过渡。所以切换的瞬间给 `<html>` 加一个 `is-theming` 类，
在那 1.2 秒里让所有元素都参与过渡：

```css
html.is-theming * {
  transition: background-color 1.2s, color 1.2s, fill 1.2s, stroke 1.2s;
}
```

再叠一圈从按钮位置扩散出去的光晕 —— 就像有人伸手拧亮了灯。

默认还跟着太阳走：晚上七点之后自动入夜，早上六点回到白天。用户手动切过一次，就不再自动干预。
